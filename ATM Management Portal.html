Know a machine is failing before it does.

Module Log

Everything a fleet operator actually needs open at once.

Eight modules, one login. Tagged the way the system tags them internally — not a marketing taxonomy.

HLTH
Terminal Health
Live status per machine — uptime, cassette levels, component wear — rolled into one glance per terminal.
OEE
OEE Metrics
Availability × Performance × Quality, calculated the way a plant floor would, applied to a cash machine.
PRED
Predictive Maintenance
Failure forecasts ahead of an actual outage, so a technician can be dispatched before a terminal goes dark.
ERR
Error Logs
Every fault code, per terminal or fleet-wide, searchable back to the exact moment it fired.
TXN
Transactions
Every withdrawal, filtered by date, terminal, or approval status — response codes decoded, not just numbers.
RPT
Reports
One-click PDF or emailed report — from a fleet-wide summary down to a single terminal's transaction ledger.
RBAC
Access Control
Admin, Operator, Viewer — a teller sees status, a technician sees everything, and nobody sees more than they should.
ONB
Onboarding
Register a new terminal and it's live in the fleet immediately — no batch import, no waiting for the next sync.
System Map

The dashboard is the front door. There's a control room behind it.

ATM Check ships as three separate services, each with its own login and its own job — not one monolith wearing three hats.

Component 01

ATM Check Dashboard

What an operator watches — terminal health, OEE, transactions, error logs, and reports, gated by role.

Runs on HTTPS :8443 This site
Component 02

ATM Prediction Engine

What forecasts failures — scheduled scoring against terminal telemetry, and periodic retraining as new data lands.

Runs as ATMPredictionEngine Runs as ATMModelTraining
Component 03

ATM Engine Console

What controls the engine — start, stop, and check both services, review recent predictions, trained model versions, and engine logs.

Under the Hood

Built to run on the hardware a bank already has.

No cloud dependency required. It installs as a Windows service against an existing SQL Server instance.

TransportHTTPS, self-signed or CA cert
DatabaseSQL Server, parameterized queries throughout
AuthHashed credentials, session-based roles
DeployWindows Service, single-file installer
UpgradesIn-place upgrade installer, config preserved
ReportingPDF export, SMTP email delivery
StackPython · Dash / Plotly · Flask sessions
AccessRole-gated routing, per-page and per-action
FootprintSingle terminal fleet or multi-branch, same build
